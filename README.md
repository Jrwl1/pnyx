# Pnyx

Pnyx is a Finland-first political accountability product. It tracks politicians, parties, promises, sources, trust context, contribution workflows, moderation, notifications, reputation signals, and official-source ingest.

Start with:

- `AGENTS.md` for agent instructions.
- `docs/index.md` for the documentation map.
- `docs/repo/truth.md` for repository truth.
- `docs/product/truth.md` for product truth.
- `docs/product/milestones.md` for milestone truth.

Run the documentation harness check with:

```bash
pnpm docs:check
```
