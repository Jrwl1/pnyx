WHAT IT DO? Frontend-ready PNYX branding pack: logo mark, wordmark, favicon, OG card, and CSS design tokens.

# PNYX Brand Assets

- `pnyx-logo-mark.svg`: primary square mark for app nav, avatars, and app-shell branding.
- `pnyx-logo-wordmark.svg`: full horizontal logo for headers, hero sections, and docs.
- `pnyx-favicon.svg`: compact favicon for browser tabs and PWA manifests.
- `pnyx-og-card.svg`: social preview image for link sharing.
- `pnyx-brand-tokens.css`: color and typography tokens plus status badge utilities.

## Design Direction

- **Hill geometry** references the Pnyx hill where assembly speech and voting happened.
- **Concentric arcs** suggest a live public forum and collective accountability.
- **Check stroke** signals verified outcomes, not just campaign claims.
- **Palette** balances institutional trust (`#0b132b`, `#162447`) with civic signal colors (`#0ea5a4`, `#f59e0b`).

## Quick Use

```html
<link rel="icon" type="image/svg+xml" href="./frontend-assets/pnyx-favicon.svg" />
<img src="./frontend-assets/pnyx-logo-wordmark.svg" alt="PNYX" />
<link rel="stylesheet" href="./frontend-assets/pnyx-brand-tokens.css" />
```
